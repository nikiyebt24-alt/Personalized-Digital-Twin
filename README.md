# Personalized-Digital-Twin
A beginner-friendly Java Swing application for student lifestyle and attendance tracking.
## Features

- 👤 Student profile
- 😴 Sleep tracking
- 🍽️ Meal tracking
- 💧 Water intake tracking
- 📖 Study hours
- 🏃 Exercise tracking
- 🏫 Attendance calculation
- 😴 Bunk calculator
- ⭐ Personalized lifestyle analysis

## Technologies Used

- Java
- Java Swing
- Eclipse IDE

## How It Works

The user enters their daily lifestyle information and attendance details.

The application analyzes the information and provides simple feedback about:

- Sleep
- Food
- Water
- Study
- Exercise
- Attendance

It also calculates how many classes can be bunked while maintaining 75% attendance.
